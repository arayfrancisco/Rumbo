# Rumbo

Juego de carreras contrarreloj en pistas de bloques low-poly, hecho con three.js y que corre por completo en el navegador.

- 5 pistas oficiales con curvas, rampas, saltos, puentes y turbos.
- Checkpoints con tiempos parciales, récord personal y auto fantasma de tu mejor vuelta.
- Editor de pistas: coloca piezas, cambia de nivel, prueba al instante y comparte la pista con un código.
- Controles de teclado y táctiles; sonido sintetizado, sin archivos externos.

## Controles

| Tecla | Acción |
|---|---|
| W / ↑ | Acelerar |
| S / ↓ | Frenar · reversa |
| A D / ← → | Girar |
| Espacio | Freno de mano (derrapar) |
| Enter | Volver al último checkpoint |
| R | Reiniciar |
| C | Cambiar cámara |
| Esc | Pausa |

Todo el contenido (código, modelos, pistas y sonidos) es original.
